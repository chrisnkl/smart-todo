# SmartTodo
---
## Overview
SmartTodo is an intelligent to-do list application for Android that leverages Google ML Kit to automatically extract and identify actionable entities from task descriptions. The app can recognize phone numbers, emails, URLs, and physical addresses within task text.

## Project Details
- **Type:** University Project
- **Platform:** Android (Kotlin)
- **Focus:** Backend Development

## Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **ML Framework:** Google ML Kit (Entity Extraction)
- **Coroutines:** kotlinx-coroutines for asynchronous operations
- **Architecture:** MVVM (Model-View-ViewModel)
---

**Note:** This is a university project and is currently in development.
